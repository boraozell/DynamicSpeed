# DynamicSpeed — First Visit Experience v34

Türkçe, ilk kez ziyaret edenlerin anlayabileceği giriş deneyimi.

## Kullanım
- Tek HTML: `DynamicSpeed_Studio_v34_First_Visit_Experience.html` dosyasını Chrome ile aç.
- Kaynak kod: Bu klasörde `python -m http.server 8000` çalıştır, `http://localhost:8000` adresini aç.

## v34 yenilikleri
- İlk ziyaretçiler için dört aşamalı, isteğe bağlı interaktif tur
- Daha anlaşılır Türkçe simülasyon ve karşılaştırma başlıkları
- İlk kez kullananlar için simülasyonun üç adımlı kullanım şeridi
- Altı terimli sade sözlük
- Hedef J ve üç farklı deney tohumu hakkında açıklayıcı not

## Kaynak kapsamı
72 karşılaştırma sonucu; iki araç kaydı (kuru yol, 2.600 araç/sa, seed 314). Sentetik simülasyon; canlı trafik sistemi değildir.
